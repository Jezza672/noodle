# Preset morph (#543)

- **Morph node** (`noodle.mod.morph`, Modulation, `noodle-nodes/src/morph.rs`): config `targets` is a list of rows (output name, `min`, `max`, taper, `a` and `b` as positions 0 to 1 along the range, stepped), one control output per row; parameter `position`. Interpolation is in position space, so a log parameter morphs along its taper; a choice switches at the midpoint; an offset parameter uses -1 to 1 with 0.5 as no move. Stateless, evaluated per sample.
- **`Edit::MorphPresets { group, a, b }`** (`noodle-app/src/session/morph.rs`): one `Command::Batch`, one undo step. It applies preset A, adds the Morph node inside the group in a frame "Morph A to B", wires an output into every parameter whose value differs between A and B, and exposes `position` as the group input `morph` (so it shows in the group's Controls). Parameters that already have a wire stay out, as does all config; the status bar names what was left out and why. Taking a parameter out is deleting its wire. `GroupPreset::paired` (noodle-core) lines the two presets up by node.
- **Picker:** the group's Presets section has "Morph between presets..." with A and B drop-downs.
- **Tests:** the node at A, B and between on linear, log, offset and stepped rows; the command wires exactly the differing parameters and skips a wired one; undo restores the graph in one step; position 0 renders like preset A and position 1 like preset B. Shown to fail by interpolating in value space and by wiring an already wired parameter.

## XY, the panel and the S13 route

- **Four corners.** The node has a second parameter `y`, and rows gain `c` and `d`: `a` is the corner at position 0 and y 0, `b` at position 1, `c` at y 1, `d` at both, blended bilinearly in position space (a stepped row takes the nearest corner's). A two-preset row has `c` = `a` and `d` = `b`, so `y` does nothing. `Edit::MorphPresets { group, presets }` takes two library presets, or four for an XY morph, which also exposes `morph y` as a group input. The picker has a "Four presets (XY pad)" box when the group has four or more presets.
- **Panel** (`noodle-app/src/morph_panel.rs`): an XY pad (A top left, B top right, C bottom left, D bottom right; a drag is one undo step, and it only shows the position when something outside drives it), a slider per row per corner, **Set from current** and **Randomise** per corner (each one undo step), and **Remove unconnected rows**, which drops rows whose wire was deleted and moves the later rows' wires to their new outputs, in one command. Randomise is seeded (`randomise_corner`), stays inside each row's range, and lands a choice on one of its choices.
- **What the command skips:** a parameter that has a wire from outside, or an automation lane. A parameter fed only by a control of the group (an input nothing outside drives, including one passed down through nested groups) is taken over, since the control no longer does anything once morphed; the notice names those controls (#570).
- **Nested groups (#570).** A wire cannot cross a group boundary, so every nested group that holds differing parameters gets a Morph node of its own, with a group input `morph` (and `morph y`). The parent's Morph has extra rows ("Position for nested groups", "y for nested groups") that give its position back, and they are wired to the nested group's input, so a slider or pad on the top Morph moves everything. A group between two such levels, with no parameters of its own, only gets the input and a pass-through wire. All of it is one `Command::Batch`, one undo step, so voice-instanced synths morph whole. Tests: three levels deep (position 0 sounds like A, position 1 like B, one undo step; shown to fail by dropping the wire into the nested input), the notice naming a taken-over control, and a library synth with a nested voice.
- **Tests:** bilinear blend at the corners and the centre, a repeatable in-range Randomise, Set from current, four presets giving two group inputs, a library effect's first two presets, the clean-up, and an app test that drags the pad.
- **S13 route** "morph a synth between two of its presets with one control" (a Lead Synth, whose voice is a nested group): select the group, open "Morph between presets...", press Morph.
