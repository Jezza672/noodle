# Clip keys that follow the timeline

Issue #348 (S05), as amended by Jeremy on 2026-11-03.

- **A clip's Key row.** An audio clip's warp has a `transpose`: the key the clip is `from` and the key it is carried `to`. In the clip panel, **Key** is a drop-down of the 24 keys with **Detect key** next to it (best effort: a pitch-class profile of the file matched against the Krumhansl-Schmuckler major and minor profiles, in `noodle-io/src/key.rs`; it says nothing for silence or noise); **To** is another drop-down with **Follow timeline** first. A transpose needs a warp; the Key row is under the warp controls and is not shown for a Sampler's sample.
- **The timeline's key.** The project has a key (View/ruler menu: Markers and selection > Key at the start) and each marker may set one in its menu (default "Same as before"); the key holds from a marker to the next that sets one. `Project::key_at` and `key_changes` read it. A marker with a key shows it in its flag.
- **Shifts.** `Key::shift_to` takes the shortest way (-6 to +5 semitones) and matches relative keys, so A minor to C major is no shift.
- **Rendering.** The shift is made by the stretch worker (`clip/pitch.rs`): the clip is stretched `r` times as long (`r = 2^(semitones/12)`) and read back at `r` frames per output frame, with cubic interpolation. A clip that spans a key change has a `PitchPath` with a step at each marker, so it changes pitch at the marker without its timing moving. A transposed clip is always stretched (Repitch is promoted to Grain). The part of the path a loop repeat or a comp take covers is sliced from the section's path. The cache key of the track input holds the transpose and, for Follow, the project's and every marker's key.
- **Formants.** By default the shift moves formants with the pitch. The Key row's **Keep formants** box (`Transpose::keep_formants`, #424) puts them back: see [formants-and-latency.md](formants-and-latency.md). Not routed: the project tempo changing after the fact.
- **Limits.** Upward shifts alias slightly above about 15 kHz at 44.1 kHz (the cubic read-back has no anti-alias filter); a Sampler ignores the transpose.

Tests: `noodle-core/src/key.rs`, `project.rs` (key per marker), `noodle-io/src/key.rs`, `noodle-nodes/src/clip/pitch.rs`, `noodle-nodes/tests/transposed_clips.rs` (pitch measured after a fixed shift, a Follow that changes at a marker, and no change in the timeline's own key; the marker test fails if the key changes are ignored). The S05 route sets the key by hand, sets the project to F minor, and has a late change that modulates at a marker.
