# Warp quality is scored against references, not hand-set tolerances

Warp quality is measured by comparing warped audio with a reference: a native render of the same song at the target tempo where we generated the audio (known truth), and the output of established stretchers such as Rubber Band where we could not (borrowed truth). Tests with hand-picked tolerances were rejected because phase-sensitive comparison is useless for stretched audio (signal-to-error ratio correlates at 0.14 with listeners), and a regression threshold taken from our own output only locks in whatever the method already does. The metrics are the Roberts and Paliwal TSM features, checked against their published listening-test dataset before one is allowed to gate CI. Their MATLAB evaluation code is not used: it is unlicensed, needs MATLAB and an old PyTorch, and assumes constant speed.
