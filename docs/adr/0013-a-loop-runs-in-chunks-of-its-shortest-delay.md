# A loop runs in chunks of its shortest delay

A wired feedback loop closes only through a node that writes its output before it reads its input (`Delay`, `Voices`), so before this the output half of a Delay ran before the block's input existed and read at least `max_frames` (128) samples back: 2.7 ms. That ruled out wired plucked strings, flanger combs, feedback FM and filters built from integrators; only the Script node could do them, as text (#547).

We make the compiler group the nodes on a loop into a **loop region** and run only those in chunks as short as the loop's shortest delay. A loop whose Delay is 40 samples runs 40 samples at a time and is exact, since each chunk reads only what earlier chunks wrote; a 300 ms echo has a chunk longer than the block and costs what it did. The user sets nothing and never sees a block size.

Two obvious designs were worse. Running the whole engine at a block of 1 costs far too much (`noodle profile --block` on the subtractive synth example: 8.7% of a core at 128 frames, 57.5% at 1, 22.1% at 4). A block-size setting on a group makes the user trade CPU against pitch range by hand. Chunking only the loop pays the per-call overhead (about half a microsecond per node) only for the nodes that need it, and the chunk is derived, so a patch cannot be set wrong.

**Consequences.** The chunk is a property of the loop breaker, asked per block (`Node::loop_chunk`), because a modulated `time` can cross below the block; the answer is the shortest delay in the block. The region owns chunk-sized buffers for its nodes' inputs and outputs, copied in and out per chunk, because lanes are laid out at the block's frame count and a chunk is not a contiguous slice of a block buffer. A loop's sound no longer depends on the engine block size. A region with a hosted plugin, a spectral node (frames 512 apart) or a delay compensation line in front of a node runs whole blocks as before and says so in its Latency section; this keeps the first version small and can be lifted later. Delay-free loops are made legal by a one-sample Feedback node, the honest minimum, rather than by solving implicit equations. Caching is unchanged: a node on a loop is already unbounded and uncached. Every shipped DSP change to the loop's sound bumps `DSP_GENERATION`.

Left out: fusing a region's nodes into one kernel to remove the call overhead (measure first), fine chunks for regions with plugins or spectral nodes, control-rate regions (zipper noise is too easy to cause automatically), and splitting polyphonic voices into separate regions (every voice runs at the chunk of the highest note).
