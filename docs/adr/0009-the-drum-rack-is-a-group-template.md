# The drum rack is a group template with empty slots

The Sampler (`noodle.instrument.sampler`) and Note Split (`noodle.event.note_split`) already exist (M9 batch B, #153), and the song kit builds a drum rack out of them, but no template in the library gave a user one. The Drum Rack template is that group with the samples left blank: eight slots on General MIDI keys (kick 36, snare 38, closed hat 42, open hat 46, clap 39, low tom 45, high tom 50, crash 49), each with `level`, `tune` and `pan` group inputs, and the Sampler's sample picked by the user per slot. It is a template, not a node, by the rule that instruments are groups of primitives. Samples are stored by content hash (ADR 0004), so a template cannot carry them; a slot without a sample is silent. The song kit's rack, whose slots are filled, stays as it is.

**Update: slots are named pads.** Each slot is a nested `Drum Pad` group named for its drum (Kick, Snare, Closed Hat, Open Hat, Clap, Low Tom, High Tom, Crash). The pad owns its key: inside are a one-output Note Split as a key filter (the `key` input sets its range), a Choke Gate, a Sampler and a Pan, with `notes`, `key`, `level`, `tune`, `pan` and `choke in` inputs and `out` and `choke out` outputs. A sample dropped on the pad (an audio clip from the timeline, or one file from the desktop) goes to the Sampler inside, so the user never opens the group. The rack is a Swing in front of the pads and a Mix.

Choke is wires between pads: a pad's `choke out` is the notes it plays (its key filter's output), and wiring it to another pad's `choke in` cuts that pad's sounding notes when this one plays. One output can feed any number of pads, and one `choke in` takes any number of outputs. There is no loop even when two pads choke each other (the closed and open hat do): `choke out` is taken before the pad's Choke Gate, and the gate is what reads `choke in`, so no pad's output depends on its own. The songs' racks (`controls: false`) keep the flat Note Split layout, so their golden renders are unchanged.
