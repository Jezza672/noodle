# Brand

The short form of the brand guidelines. Files are in [assets/brand](../assets/brand/README.md).

## Name

**Noodle**, capital N, in prose and window titles. "A node-based DAW". Site: noodledaw.com. The glyph N is artwork only and never goes into running text.

## The three marks

1. **Wordmark, Medium** (primary): the N graph in place of the N, then "oodle" in Space Grotesk Medium, tracking −2.5%. Colourways: lime on canvas, ink on paper, lime-ink on lime, white on canvas.
2. **Wordmark, Bold** (variant): Space Grotesk Bold with the heavier N, tracking −3%. For splash screens, stickers and slides.
3. **App icon tile**: the N graph in lime-ink on a lime rounded square (112 of 120 units, radius 28). The only mark that appears alone.

| Place | Use |
|---|---|
| App icon, dock, taskbar, window icon, favicon | Tile |
| Window title, menus, About text, docs, commit messages | Plain text "Noodle" |
| README banner, website header | Wordmark, Medium |
| Splash screen, stickers, slides | Wordmark, Bold |

## Never

- The tile beside plain type.
- Port circles in place of the o's.
- Stretching, recolouring outside the four colourways, mixing the Medium N with Bold text, italics, shadows.
- Busy backgrounds behind the wordmark.
- The bare N graph (no tile) as an app icon.

## Size and space

Keep clear space of half the N's width around the wordmark. Minimum wordmark width 96 px on screen; below that use plain text. Minimum tile 16 px.

## Colour

From `theme.rs`: lime `#C8F169` (accent), canvas `#0E1014`, panel `#171A20`, blue `#3C5AA8`, coral `#FF7A6B`, outline `#343A47`. For light surfaces: paper `#F4F4F1`, ink `#14161B`. Lime-ink `#1C2A05` is the wire on lime.

## Type

Space Grotesk (wordmark, headings) and Inter (body text on the site and docs). Both are SIL OFL, from Google Fonts. Using them inside the app is a separate change.
